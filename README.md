itclase07 — Sitio Web Descripción

AIMAZING es un sitio web de indumentaria inspirado en un diseño contemporáneo, moderno y minimalista.

El proyecto fue desarrollado como parte de una actividad de desarrollo web, aplicando HTML, CSS, Bootstrap y diseño responsive.

Tecnologías utilizadas HTML5 CSS3 Git GitHub

Diseño Responsive

El sitio fue desarrollado utilizando un enfoque Mobile First.

Se utilizaron Media Queries para adaptar el contenido a diferentes tamaños de pantalla:

📱 Celular: hasta 767px 💻 Tablet: desde 768px 🖥️ Desktop: desde 1024px

Además, se utilizó CSS Grid y Bootstrap para organizar y adaptar los diferentes componentes.
